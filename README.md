# تسلّى غو — نسخة الأندرويد

ألعاب سهرات وحكي على موبايل واحد: **الشلة** (3 إلى 12 لاعب) و**الثنائي**.
هالمستودع بيحوّل التطبيق لملف **APK** بينزل على أي موبايل أندرويد، وكل البناء بيصير على سيرفرات GitHub. ما بتحتاج Android Studio ولا كمبيوتر قوي.

## شو في بالمستودع

```
tasalla-go/
├── www/                       التطبيق نفسه (HTML و CSS و JavaScript)
├── assets/                    صور مصدر لأيقونة التطبيق وشاشة البداية
├── keystore/debug.keystore    مفتاح توقيع ثابت، حتى كل تحديث ينزل فوق القديم
├── .github/workflows/
│   └── build-apk.yml          خطوات بناء الـAPK على GitHub
├── capacitor.config.json      اسم التطبيق ومعرّفه وألوان شاشة البداية
├── package.json               المكتبات المطلوبة (Capacitor)
└── .gitignore
```

## طلّع الـAPK بخمس خطوات

1. **اعمل حساب على GitHub** من github.com إذا ما عندك.
2. **اعمل مستودع جديد:** زر **+** فوق ← **New repository** ← الاسم `tasalla-go` ← خليه **Public** أو **Private** ← **Create repository**.
3. **ارفع الملفات:** بصفحة المستودع اكبس **uploading an existing file**، واسحب **كل محتويات** مجلد `tasalla-go` (مو المجلد نفسه) ← **Commit changes**.
   - تأكد إنو مجلد `.github` انرفع. إذا ما شفته (بعض الأجهزة بتخفي المجلدات اللي بتبلش بنقطة): **Add file** ← **Create new file** ← اكتب بالاسم `.github/workflows/build-apk.yml` ← الصق محتوى الملف ← **Commit changes**.
4. **استنى البناء:** افتح تبويب **Actions**. البناء بيبلش لحاله وبياخد حوالي 5 دقائق. إذا ما بلّش: اختار **Build APK** ← **Run workflow**. لما تطلع علامة ✓ خضرا، خلص.
5. **نزّل على الموبايل:** من الموبايل افتح صفحة المستودع ← **Releases** (عالجنب أو تحت) ← آخر إصدار ← اكبس على ملف `tasalla-go-v….apk`. افتح الملف، وإذا سألك اسمح **بتثبيت التطبيقات من هالمصدر**.

> إذا المستودع **Private**، صفحة Releases بتفتح بس إذا كنت مسجّل دخول. فيك كمان تنزّل الملف من صفحة التشغيل بتبويب Actions تحت **Artifacts** (بينزل مضغوط zip، فكّه وافتح الـAPK).

## تعديل التطبيق ونشر تحديث

1. عدّل الملفات جوّا `www/` (مباشرة على GitHub بزر القلم ✏️، أو ارفعها من جديد).
2. غيّر `"version"` بـ `package.json` (مثلاً `2.0.2`).
3. غيّر `VERSION` بأول `www/sw.js` بنفس الرقم (هاد للنسخة اللي على المتصفح).
4. أي حفظ على فرع `main` بيعمل APK جديد لحاله بصفحة Releases. نزّله وثبّته فوق القديم: البيانات (البطاقات اللي انلعبت والأسماء) بتضل.

- **المحتوى:** `www/js/group-content.js` و `www/js/couples-content.js`.
- **الألوان:** بأول `www/css/shared.css`.
- **اسم التطبيق:** `appName` بـ `capacitor.config.json`.
- **الأيقونة وشاشة البداية:** بدّل الصور بمجلد `assets/` بنفس الأسماء والمقاسات (`icon-only.png` 1024×1024، `icon-foreground.png` و `icon-background.png` 1024×1024، `splash.png` و `splash-dark.png` 2732×2732).

## أشياء لازم تعرفها

- **لا تغيّر `appId`** (`com.tasallago.app`) بعد ما توزّع التطبيق. إذا تغيّر، الموبايل بيعتبره تطبيق تاني.
- **لا تحذف `keystore/debug.keystore`.** إذا تغيّر المفتاح، التحديث ما بينزل فوق النسخة القديمة ولازم تمسحها أول (وبتروح البيانات).
- هالـAPK نسخة **debug**: ممتازة للتجربة والتوزيع على الأصحاب. لمتجر **Google Play** بدك نسخة **release** موقّعة بمفتاح خاص فيك وبصيغة AAB، ومنضيفها لما يصير عندك حساب مطوّر.
- زر **الرجوع** بالموبايل: بالشاشة الرئيسية بيطلع من التطبيق، وبنص لعبة لازم تكبسه مرتين ورا بعض حتى ما تضيع اللعبة بالغلط.
- التطبيق بيشتغل بالكامل **بدون إنترنت** وما بيطلب أي صلاحية.

## على الكمبيوتر (اختياري، للمطوّرين)

بدك Node.js 20 و Android Studio:

```
npm install
npx cap add android
npm run android:assets
npx cap sync android
npx cap open android
```

وبعدين من Android Studio: **Build ← Build APK(s)**.
